# SVGF-like + TAA 实验

2026-11-12。新增 `reconstruction:'svgf'`，界面在“交互加速”的去噪选项中选择
“SVGF + TAA（实验）”。默认仍为原来的 temporal。无需训练数据或神经网络权重。

## 管线

1. 复用现有 3×3 重建的平均命中深度作重投影假设；颜色累积直接使用原始随机帧。
2. 双线性历史采样逐 tap 做 10% 相对深度检查，至少 25% 有效权重才接受。
   保存颜色、亮度一阶/二阶矩和有效样本数，最多 32 个有效样本。
   部分历史被拒绝时，按混合权重更新有效样本数，避免把历史年龄当成有效采样量。
   历史颜色约束在当前原始 3×3 邻域范围内。
3. 根据亮度矩估计方差；历史不足时混合局部空间方差。方差除以有效样本数作为
   累积均值的不确定度近似；它没有精确处理重投影、相关样本及颜色约束带来的偏差。
4. 三轮步长 1、2、4 的 3×3 à-trous 滤波。亮度权重使用方差，深度权重保留 0.5 下限，
   避免随机层变化造成的假边缘把噪点保留下来；方差按归一化权重平方传播，另用
   原始亮度矩估计保留 25% 方差下限，避免多轮相关采样导致方差过低而保留亮点。
5. 独立 TAA 历史作最终稳定，颜色限制在滤波后 3×3 邻域内；随屏幕运动降低历史权重。
   保持标定整数像素采样，不添加相机 jitter。

这是针对缺少稳定法线和表面深度的随机 splats 的启发式适配，并非完整复刻 SVGF。
原始样本历史与 TAA 历史分开，最终模糊输出不会反馈进亮度矩。
四种相机沿用同一深度约定；全景邻域与重投影支持水平周期寻址。
模型、内参、方法、背景、分辨率或模式改变时拒绝历史；支持 `resetHistory:true`。
截图默认仍使用完整排序，逐字节恢复。

## 测量与限制

300 万点 1023 SOG，NVIDIA Blackwell / Edge 157，960 宽，三条针孔相机短轨迹。
每条轨迹 8 帧预热、24 帧采样；每个模式独立连续运行，质量与计时分开测量。
这些是本机短轨迹结果，不能代表其他设备、任意透明场景或长时间运动。

| 轨迹 | 原始随机 MAE | 现有 temporal MAE | 首版 SVGF | 调整后 SVGF |
| --- | ---: | ---: | ---: | ---: |
| view0 | 19.607 | 7.966 | 4.812 | 3.903 |
| view1 | 20.354 | 7.547 | 4.685 | 3.720 |
| view2 | 16.740 | 7.316 | 4.051 | 2.483 |

MAE 为 RGB 平均绝对字节误差，对应排序图像。调整后比首版 SVGF 误差降低约 19–39%，
但 view0/view1 边缘 MAE 从 15.94/11.83 上升到 16.81/13.27，反映更强平滑的代价。
误差包含噪声、模糊和合成差异，
不能把 MAE 下降当成纯噪声下降或细节无损。实景仍有可见残余颗粒，尚未 noise-free。
完整计时汇总见 [机器记录](benchmarks/svgf-taa.json)，不能由短测试的墙钟数值宣称普遍提速。

新增资源按需分配：相对原始随机帧共 92 bytes/pixel 重建纹理，960×540 约 47.69 MB，
1920×1080 约 190.77 MB；不含原本随机深度和颜色目标。切换模式会缓存资源，
如果同尺寸也用过旧 temporal，再保留 32 bytes/pixel；resize/dispose 释放，内存统计包含它们。

合成测试覆盖 GS/GUT、四种镜头的噪声下降与精确截图，以及独立历史重置、模式切换、
奇数尺寸、细线对比度和移动遮挡露出。合成细线中心对比度为排序参考的 60.3%（首版 SVGF 65.9%，旧 temporal 68.7%），说明更平滑有细节代价；
遮挡露出夹具的旧红色最大残留为 3/255。合成夹具通过不代表任意实景没有拖影。
